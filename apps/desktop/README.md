# Atlas Desktop

The Atlas Tauri desktop application: React/TypeScript in `src` and the Rust engine in `src-tauri`.

From the repository root:

```bash
pnpm --filter desktop test
pnpm --filter desktop lint
pnpm --filter desktop build
pnpm --filter desktop tauri dev
```

Indexing requires Ollama and an embedding-capable model. Local generation uses a separately configured Ollama generation model. OpenRouter is optional, must be enabled for the active workspace after an exact cloud disclosure, and remains an explicit send destination. Atlas inspects the complete bounded outbound payload before transmission.

The interface is organized as Launcher → Workspace with sibling Ask and Find modes. History is a collapsible workspace-scoped rail; citations, files, previews, and pinned context share the contextual Evidence pane.
